Google Drive 자동 동기화

Google 계정으로 로그인하면 내 드라이브의 지정 폴더에 백업 파일(smart_car_logbook_sync.json)을 직접 저장하고 동기화합니다.

미연결

슬래시(/)로 하위 폴더까지 지정할 수 있으며, 폴더가 없으면 자동으로 생성됩니다.

Google Cloud Console 설정 방법 보기
  1. Google Cloud Console에서 프로젝트 생성 후 Google Drive API를 사용 설정합니다.
  2. API 및 서비스 → 사용자 인증 정보 → OAuth 클라이언트 ID 만들기(웹 애플리케이션)를 선택합니다.
  3. 승인된 JavaScript 출처에 본인의 GitHub Pages 주소(예: https://아이디.github.io)를 등록합니다.
  4. 발급된 클라이언트 ID를 위 입력칸에 붙여넣고 저장한 뒤 로그인하세요.
